# Henil Prajapati – Portfolio

React + Vite single-page portfolio. All content lives in `src/data.js`.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build      # outputs to dist/
npm run preview
```

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. On vercel.com choose Add New → Project and import the repository.
3. Vercel detects Vite automatically (build command `npm run build`, output directory `dist`). Click Deploy.

Netlify works the same way with build command `npm run build` and publish directory `dist`.
